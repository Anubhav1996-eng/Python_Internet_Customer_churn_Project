# Python_Internet_Customer_churn_Project

### Customer Churn Analysis

Analyzed customer data to identify key factors influencing **customer churn and retention**. Performed data cleaning, exploratory data analysis, and customer segmentation using **Python, Pandas, Matplotlib, and Seaborn**. Analyzed churn patterns across contract type, customer tenure, monthly charges, payment methods, and customer demographics. Generated business insights to help identify high-risk customer segments and support data-driven retention strategies.

### Analytical Methods Used

* **Data Cleaning:** Handled missing values, duplicates, data types, and unnecessary columns.
* **EDA:** Analyzed numerical and categorical variables using descriptive statistics.
* **Outlier Detection:** Identified potential outliers using Box Plots and the IQR method.
* **GroupBy Analysis:** Compared churn across contract, gender, senior citizen, partner/dependent, and payment-method segments.
* **Customer Segmentation:** Created tenure and monthly-charge categories.
* **Pivot Table Analysis:** Compared contract types with churn status.
* **Data Visualization:** Used Count Plots, Histograms, and Box Plots to identify patterns.
* **Churn Analysis:** Calculated overall and segment-wise churn rates.
